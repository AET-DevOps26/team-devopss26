# Web Client

A modern React + Vite SPA with TanStack Router, TanStack Query, Tailwind CSS v4, and shadcn/ui.

## Getting Started

```bash
npm install
npm run dev
```

The dev server runs on port 3000.

## Building for Production

```bash
npm run build
npm run preview
```

## Testing

Uses [Vitest](https://vitest.dev/). Tests can be run with:

```bash
npm run test
```

## Stack

- **Framework:** React 19
- **Bundler:** Vite 8
- **Routing:** TanStack Router (file-based)
- **Data Fetching:** TanStack Query
- **Styling:** Tailwind CSS v4
- **UI Components:** shadcn/ui + Base UI
- **State Management:** Zustand
- **Devtools:** TanStack Devtools, React Devtools
